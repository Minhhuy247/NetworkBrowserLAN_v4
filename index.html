PROJECT GUIDE / MODULE 05
Hướng dẫn demo
Trình tự thao tác trước giảng viên, đúng trọng tâm môn Lập trình mạng.
?

        
Quy trình demo nhóm 2 người
  1. Máy Server: chạy python server.py trên VS Code; đọc địa chỉ IPv4 từ ipconfig.
  2. Client 1 + Client 2: truy cập bằng Chrome vào http://IP_SERVER:8080, nhập IP Server thủ công và đặt tên riêng để kết nối.
  3. HTTP GET: nhập URL mẫu http://IP_SERVER:8080/demo, xem status, độ dài, số thẻ p/div/span/img.
  4. HTTP POST: nhập dữ liệu vào ô POST, bấm GỬI REQUEST và quan sát HTML Server trả về.
  5. HTTP HEAD: quan sát headers, Content-Type, Content-Length. Không có body.
  6. Chat: gửi tin riêng, sau đó gửi nhóm. Quan sát cập nhật thời gian thực mà không cần làm mới trang.
  7. Tệp: Client 1 chọn file gửi cho Client 2; Client 2 bấm Tải xuống, kiểm tra SHA-256 và mở file.
  8. Ngắt kết nối: một Client bấm Ngắt kết nối. Server ghi thời điểm disconnect và giảm số Online.
Kiến thức cần giải thích: TCP/IP, socket.connect, bind/listen/accept, HTTP method, request/response, Content-Length, concurrent threads, SSE, byte stream và checksum.
